#  Fruit Freshness Detection (CNN & Streamlit)

This project classifies whether fruits (apples, bananas, oranges) are fresh or rotten using a custom Convolutional Neural Network (CNN) built with TensorFlow/Keras and deployed via Streamlit.

##  Tech Stack
- **Deep Learning:** TensorFlow, Keras (CNN)
- **Web UI:** Streamlit
- **Image Processing:** Pillow, NumPy

##  How to Run Locally
1. Clone this repository:
   ```bash
   git clone <repo-url>
   pip install -r requirements.txt
   streamlit run fresh.py
